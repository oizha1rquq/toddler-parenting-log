# 脑海中的橡皮擦|阿尔兹海默病

> 更新时间：2026-09-17 (UTC+8)

鱼的记忆只有七秒

但是在疾病的侵蚀下

人类的记忆可能连七秒都没有

 “记忆3秒钟”

是今年世界阿尔茨海默病日的主题

如果您的家人诊断为“阿尔兹海默病”，那么您需要做好打一场漫长而艰辛的“持久战”的思想准备。您可能会面临身心疲惫、经济拮据的挑战，可能会经历希望和无助，温情和烦躁，坦然与愧疚的情感起伏。

**什么是阿尔兹海默症**

阿尔茨海默病（Alzheimer Disease）是一种起病隐匿的进行性发展的中枢神经系统退行性疾病。主要表现为渐进性记忆障碍、认知功能障碍、人格改变及语言障碍等神经精神症状。

阿尔茨海默病的患病风险随年龄递增：65岁以上老人的患病率约为3%～7%，85岁以后就会攀升到25%～33%。

**阿尔茨海默病 = 老年痴呆？**

痴呆不是一种病，它是由不同疾病引起，以记忆障碍、生活能力减退和精神行为异常为主要表现的综合征。

如脑老化引起的有阿尔茨海默病，脑中风引起的叫“血管性痴呆”，脑外伤引起的“外伤后痴呆”等等。

不同类型痴呆症的发病年龄、是否遗传、临床表现、进展快慢和治疗方法等都不同，需要到专业医疗机构诊治。

**阿尔兹海默症的征兆**

“痴呆症”最常见的类型

是阿尔茨海默病，

也就是我们常说的

“老年性痴呆”。

是由大脑退化引起，

常隐匿起病，逐渐进展。

从早期记忆力减退，到中晚期迷路、不认识家人，需要4-8年时间。最终发展到完全失去生活自理能力，可能需要10年或更长。

➤ 疾病早期：主要表现为记忆力减退，日常生活可能不受影响或轻微影响。很多人并不知道这是疾病状态，以为是自然衰老。其实此阶段是就诊治疗的最佳时期，通过有经验的医生诊治判断，给予治疗干预，可以延缓疾病恶化。

➤ 疾病中期，患者记忆力减退加重，语言表达和理解能力下降，空间感下降，出门迷路。在家分不清卧室卫生间，有时无法辨认亲人。还会出现精神行为异常，比如多疑、幻觉、易怒、攻击等。此时的患者已经不能安全的独自生活，需要与人同住，接受更多照顾。照料者要理解患者种种异常的行为举止不是故意作对，而是疾病导致，需要更多耐心和技巧，尽量让患者过上舒适、安全和体面的生活。

➤ 疾病晚期，患者生活各方面都需要人照顾，甚至已经到了生命的终末期。此时的照顾需要特别注意患者的卫生、营养和尿便情况，避免肺炎、褥疮等疾病。有些家庭可能将患者送至照料机构。无论谁照顾，在哪里照顾，我们的目的都是让他生命中最后一段时光过得舒适和有尊严。

**阿尔兹海默症的康复治疗**

首先要知道的是，阿尔茨海默病是退行性疾病，以目前的医疗条件，一旦发生，是不可逆转的。康复锻炼的目的是减缓疾病引起退化的速度，提高患者的生活质量，延长患者的生命。

面对一名阿尔茨海默症的患者，

康复要做的第一件事是什么呢？

评估！评估！评估！

根据患者的身体情况，对患者展开全方位，多角度的评估。包括：运动功能评估、感觉与知觉功能评定、平衡与协调功能评定、日常生活活动能力、工作能力、社会参与程度的评定、情绪评定等等。

通过这些评估，康复团队将判断患者康复潜力，制定合理的康复锻炼方案，减缓阿尔茨海默病患者退化的速度，提高患者的生活质量。

例如，把需要系鞋带的鞋换成使用魔术贴固定的鞋，简化了穿鞋的步骤或方法，使患者容易接受这样的生活。科学的康复锻炼能够缓解阿尔茨海默病对患者的影响，提升患者生活质量，延长患者的生命。
