# 动态 ||  开讲啦！市中心医院中层干部系列培训讲堂第一课

> 更新时间：2026-09-17 (UTC+8)

12月29日下午，漯河市中心医院中层例会在3号楼会议中心善济厅召开，此次会议特邀了漯河市人大常委会党组副书记、副主任陈平莅临授课，由此开启了医院中层干部系列培训讲堂第一课，院领导班子及全院200余名中层干部参加了此次培训。

陈平以《新时代医务工作者的责任担当》为题，从健康中国的战略要求和区域性医疗中心建设谈起，围绕新时代医务工作者的责任担当，干部职工的格局、视野、心胸和情怀等方面做了细致深入的阐述，激励广大医务工作者要做胸怀全局的明白人、厚德仁爱的善良人、守正创新的带头人、幸福快乐的追梦人。

陈平表示，市中心医院作为地区性医疗服务中心，承担着主力军、主阵地、先锋队的历史责任，要进一步强化全周期健康管理服务，提升疾病防控服务体系，搭建科研创新平台，优化人才队伍建设，推进分级诊疗制度化和全科医生培养机制，为捍卫人民健康做出更多更大的贡献。

王海蛟表示，陈平主任高屋建瓴，为全体中层干部做了一堂内容详实、重点突出、针对性和实用性都非常强的精彩课程，希望全体中层干部学有所获，在今后的工作中不断提高履职能力和综合素质，锐意创新、勇争一流、敬业爱岗、和衷共济，汇聚起团结拼搏、创新发展的磅礴力量，在健康漯河发展的史册上再创佳绩、再谱华章！
