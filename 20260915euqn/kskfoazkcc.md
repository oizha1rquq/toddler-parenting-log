# 广州做试管婴儿要结婚证吗？所需证件要哪些？

> 更新时间：2026-09-15 (UTC+8)

随着试管技术的发展和应用，越来越多的不孕不育家庭通过试管实现生子梦想，不仅如此，试管技术还另辟蹊径，为众多有特殊需求的人群服务。根据国家发布的人类辅助生殖技术的名单，在广州可以做开展辅助生殖技术的医院一共有18家，关于这些医院能不能做试管的问题，我们特意为大家整理了广州试管所需证件。**（如果还想了解更多的试管婴儿流程、费用、成功率，可点击在线咨询，询问专业顾问，解决相关问题）**

广州做试管要不要结婚证

广州的辅助生殖机构数量不少，因此网上有很多人传言说在广州做试管，其实这只是错误的传言，因为广州的私立试管机构不少，有很多机构不正规，为了谋取私立，因此不要结婚证也可以进行辅助生殖手术。如果是在正规的试管机构做手术，是不行的。

正规的试管机构做手术需要结婚证

法律依据：

依据国家卫生部发布的《人类辅助生殖技术管理办法》：医务人员必须严格贯彻国家人口和计划生育法律法规，不得对不符合国家人口和计划生育法规和条例规定的夫妇和单身妇女实施人类辅助生殖技术。

在广州地区开展试管婴儿技术的治疗必须要符合条件，而试管婴儿的条件包含了适应症以及证件。做相关检查的话只需要出示夫妻双方的身份证即可，在建档的时候，育龄夫妻双方就必须要出示身份证和结婚证原件，并签署承诺书，完成相关的手续，才可以开展试管婴儿手术治疗。

广州哪家医院做试管不要结婚证

截止目前，广东经批准开展辅助生殖技术的医疗机构一共有56家，广州就有18家，公立和私立的医疗机构都有，其中，中山大学附属第一医院、广州医科大学附属第三医院、广东省妇幼保健院、孙逸仙纪念医院等医疗机构都全国范围内比较热门的，但是不管是公立医院还是私立医院做试管都是需要结婚证的。

广州试管所需证件集锦

国家卫计委表示为了方便做试管婴儿的患者，减少办事程序，就生育证明检查程序作了简化，不再需要准生证，只需结婚证、身份证加上书面保证即可。因此在广州辅助生殖医疗机构做试管，除了三证外还需要提供一些材料，请看详细信息。

以下是广州试管所需证件：

1. 身份证件：夫妻双方居民身份证及户口本原件及复印件各一份;

2. 医院证明：在市级或者市级以上的医院检查，结果显示为男性或女性不孕的诊断书原件及复印件各一份;

3. 关系证件：证明夫妻关系的证件，也就是结婚证;

4. 在相关部门填写试管婴儿证明申请表，记得是一式三份;

注：不孕不育症病人提交的三证中全部的名字、身份证号码务必一致;如名字不一致，务必得在本地公安局去证实姓名和在用名是相同人并盖公章;身份证件或是结婚证书遗失或是到期，务必去先关企业再次申请办理;另一个，办准生证必须要去本地派出所盖章。
